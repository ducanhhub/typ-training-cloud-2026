# Bài làm Tuần 1 - Nguyễn Đức Anh

## Phần 1: Giới thiệu tổng quan về Git

### 1. Git là gì?
- Git là một hệ thống quản lý phiên bản phân tán (Distributed Version Control System - DVCS).
- Nó giúp theo dõi các thay đổi trong mã nguồn, cho phép nhiều người làm việc chung trên một dự án mà không bị đè code của nhau.

### 2. Khác biệt giữa Git và GitHub
- **Git**: Là công cụ chạy dưới máy local để quản lý lịch sử phiên bản code.
- **GitHub**: Là dịch vụ đám mây (cloud) dùng để lưu trữ các repository Git trên internet.
